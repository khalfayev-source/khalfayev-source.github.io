Aquamaster AI Bridge

A private Google Drive bridge that runs on its owner's personal Windows computer.

HomePrivacy Policy

Purpose

Aquamaster AI Bridge lets the owner of Aquamaster send short, structured commands from a chat assistant to their own Windows computer, and receive the results, using a folder in the owner's Google Drive as the exchange point. It is a personal tool for one person's own account. It is not offered to the public and it accepts no other Google account.

How it works

  1. A command is saved as a small file in the Commands folder of the owner's Google Drive folder "Aquamaster AI Bridge".
  2. A Python program on the owner's computer, started by Windows Task Scheduler every five minutes while the owner is signed in to Windows, lists that folder and downloads new command files (at most 64 KB each).
  3. The program checks each command against a fixed list of allowed command types. Simple read-only status and diagnostic commands (for example a connectivity test) are answered automatically. Anything else is only queued: the owner sees a Windows notification and a short notice in the Results folder. It is not carried out automatically.
  4. The answer is written as a new Google Doc in the Results folder of the same Drive folder.
  5. Each processed command is recorded in a local log on the computer, and the Results folder is checked for an existing result before a new one is written. These checks reduce the risk of a command being processed twice; they are not an absolute guarantee.

Google permissions requested

ScopeWhy it is needed
drive.readonlyTo list the Commands and Results folders and to read the command files the owner (or the owner's assistant) placed there.
drive.fileTo create result documents in the Results folder. This scope only covers files the application itself creates.

The program contains no code to delete, trash, share, copy or edit existing Drive files, or to change their permissions. Its requests to Google are limited to a fixed list: list files, read or export a file's text, create a file, read the account's email address, and refresh or revoke its own sign-in.

Who can use it

The application is used only by its owner. It runs on the owner's computer, signs in only to the owner's Google account, and refuses to continue if a different account is chosen during sign-in. There is no website, server or hosted service behind it; this page only describes it.
